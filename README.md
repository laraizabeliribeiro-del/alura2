# Website p5.js - Dashboard Otimizado

🎨 Website moderno e responsivo construído com HTML, CSS, JavaScript e p5.js

## 📋 Características

### ✨ Funcionalidades Principais
- **Layout Responsivo**: Adaptado para todos os tamanhos de tela (desktop, tablet, mobile)
- **Navegação Suave**: Menu interativo com transições elegantes
- **Visualizações p5.js**: Gráficos animados e interativos
- **Dashboard Completo**: Seções de home, dashboard, itens e contato
- **Formulário de Contato**: Validação e notificações
- **Rodapé Informativo**: Com links e informações de contato

### 🎯 Seções do Site

#### 1. **Home**
- Bem-vinda com visualização animada de partículas
- Conexão visual entre elementos
- Call-to-action para o dashboard

#### 2. **Dashboard**
- Visualização p5.js com ondas animadas
- Gráfico de barras em tempo real
- Card com estatísticas
- Design profissional e moderno

#### 3. **Itens**
- Grid responsiva de cards
- Design minimalista
- Cada item com descrição e botão de ação

#### 4. **Contato**
- Formulário completo com validação
- Campos para nome, email e mensagem
- Notificações de sucesso/erro

## 🚀 Como Usar

### Instalação

1. **Clone o repositório**
```bash
git clone https://github.com/laraizabeliribeiro-del/alura2.git
cd alura2
```

2. **Acesse a branch do projeto**
```bash
git checkout website-p5js
```

3. **Abra o arquivo index.html**
- Opção 1: Clique duplo no arquivo `index.html`
- Opção 2: Use um servidor local (recomendado)

### Usar Servidor Local (Recomendado)

**Python 3:**
```bash
python -m http.server 8000
```

**Node.js (http-server):**
```bash
npm install -g http-server
http-server
```

**PHP:**
```bash
php -S localhost:8000
```

Depois, abra `http://localhost:8000` no seu navegador.
